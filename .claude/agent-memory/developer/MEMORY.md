- [Commit cadence](feedback_commit_cadence.md) — commit every 2-3 steps; on resume from a turn-limit cutoff, commit first, before anything else.
- [fs guard + gitattributes gotchas](feedback_fs_guard_and_gitattributes.md) — no-write-gate-bypass bans fd-based fs calls repo-wide (even in comments); root .gitattributes normalizes CRLF, breaks byte-exact fixtures unless scoped `-text` override added first.
- [Mutation testing safety](feedback_mutation_testing_safety.md) — never `git checkout -- <file>` to undo a mutation when that file has uncommitted real fixes; commit first or revert by hand.
- [Orphan process before verify](feedback_orphan_process_before_verify.md) — on resume, check/kill orphaned node.exe on port 7333 before npm test/verify/e2e; EADDRINUSE looks like a regression but isn't.
- [Isolate live session before blaming a bug](feedback_isolate_live_session_before_blaming_bug.md) — big aggregate deviation vs ccusage/etc: diff per-session first, the active/growing session is usually the whole gap.
- [Nested real-suite fork bomb](feedback_nested_real_suite_fork_bomb.md) — a test spawning the real vitest suite must exclude its own test file, or it recursively re-triggers and forks exponentially.
- [Single-use token + manual hook test](feedback_single_use_token_manual_test.md) — never run `node hook.cjs < stdin` diagnostics against the real guarded path while a GUARD/DANGER/PUSH.ok token exists; the hook can't tell manual calls from real ones and will silently consume it.
- [Self-test suite consumes real token](feedback_selftest_suite_consumes_real_token.md) — don't run the full `_selftest.cjs` (it writes/deletes the real GUARD.ok internally) until all real guarded edits for the current token are already done; verify new logic via standalone scratchpad scripts first. Also applies to a scratchpad *copy* run with cwd=repo root.
- [Autonomous hook edit blocked](feedback_autonomous_hook_edit_blocked.md) — Claude Code's own auto-mode classifier categorically rejects any Edit/Write to `.claude/hooks/**`, content-independent; don't retry, stop and hand off to the user.
- [GUARD.ok scope prose leak](project_guard_scope_prose_leak.md) — never backtick a `.cjs` filename in GUARD.ok prose outside "## Kapsam"; `parseGuardScope()` parses the whole file and silently widens the real scope.
