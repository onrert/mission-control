### 2.1 BLOKLAYICI B1 (tur 5) — birincil katmanın **hiç öz-testi yok**; mutasyonu YEŞİL

Brief'in doğrudan sorusu: *"Sentinel'i devre dışı bırakan mutasyon KIRMIZI mı?"* → **HAYIR.**

`installNetworkCapabilitySentinel`'in `patch()` gövdesini tamamen no-op yaptım
(`usage-aggregator.test.ts:71-82`) — yani sentinel hiçbir şeyi kuşatmıyor, `calls` daima boş:

| Mutasyon | Sonuç |
|---|---|
| **M7** — `patch()` no-op (sentinel tamamen devre dışı) | **YEŞİL — 52/52** |
| **M8** — `expect(sentinel.calls).toEqual([])` → `expect(Array.isArray(...)).toBe(true)` | **YEŞİL — 52/52** |

Kök neden: dosyada `sentinel.calls`'ın **pozitif kontrolü yok**. `calls` yalnızca tek bir yerde,
tek bir negatif iddiada kullanılıyor (`:474`). Bir çitin "çalıştığını" ancak onu **kasten
tetikleyip** yakaladığını görerek kanıtlayabilirsiniz; bu dosyada öyle bir test yok.

**Neden bu bloklayıcı — sessiz ölüm senaryosunu canlı ürettim.** Sentinel, `import`'suz global ağ
API'lerinin (S1 yakalanmış `fetch`, S3 `WebSocket`) **TEK** savunması; AST katmanı onları hiç
görmüyor (import ifadesi yok). M7 + ürün koduna sıradan bir `new WebSocket('ws://127.0.0.1:…')`:

```

npm run verify:  typecheck+lint+build YEŞİL,  Tests 1303 passed | 4 skipped (1307),  exit 0
dinleyiciye gelen gerçek istek: 106 adet  (GET /CANLI-S3-websocket)
```

Yani sentinel bir gün sessizce bozulursa (refactor, Node'un undici'yi `net.connect` üzerinden
çağırmayı bırakması, `vi.restoreAllMocks` etkileşimi…) **hiçbir test kırmızı vermez** ve o andan
itibaren bu sınıf tamamen korumasızdır. CLAUDE.md'nin adıyla koyduğu en pahalı hata sınıfı budur
(*"kapı sessizce ölür"* — hook'ların `.js` uzantısı yüzünden iki feature boyunca ölü koşması).
Katman "BİRİNCİL koruma" ilan edildiği için risk tur 4'tekinden **daha** büyük: artık AST katmanı

**Muhtemel dosya:satır:** `tests/features/usage/server/usage-aggregator.test.ts:65-116`

### 2.2 BLOKLAYICI B2 (tur 5) — `process.binding('tcp_wrap')` **canlı sızıntı** (pratik)

Tur 3 ve tur 4'te bu vektörü *borç* saymıştım; gerekçem açıkça **"canlı sızıntı kanıtlanmadı"**
idi. Bu turda kanıtladım — gerekçe düştü.

Ürün koduna konan biçim **gizlenmemiş, `any`'siz, tip-güvenli, lint-temiz** TypeScript
(tam metin: `usage-aggregator.ts` başına 20 satır arayüz tanımı +
`const qaProc = process as unknown as { binding: (name: string) => … }`, gövdede
`qaHandle.connect(qaReq, '127.0.0.1', 45922)` + `writeUtf8String(...)`):

```
npx tsc --noEmit         → exit 0
npx eslint <dosya>       → exit 0
usage çit testleri       → 52 passed (52)      ← İKİ KATMAN DA GÖRMÜYOR
npm run verify           → exit 0,  Tests 1303 passed | 4 skipped (1307)
bağımsız dinleyici (127.0.0.1:45922) günlüğü:
  RAW-TCP-CONNECT from 127.0.0.1:59820
  RAW-DATA "GET /CANLI-S2-tcpwrap HTTP/1.1\r\nHost: 127.0.0.1\r\nConnection: close\r\n\r\n"
  verify koşusu boyunca: 29 adet gerçek TCP bağlantısı + HTTP isteği
```

Brief'in "pratik mi teorik mi" testi: **gerçek istek çıkıyor ✔ + testler yeşil kalıyor ✔ → PRATİK.**
Teorik bit taşıma değil; ham TCP soketi kuruluyor ve tam bir HTTP istek satırı karşı tarafa
teslim ediliyor.

**Asıl kanıt burada — ikincil katmanın bu kanaldaki koruması yapısal olarak SIFIR.** Çitin tek
savunması `FORBIDDEN_CALL_PATTERNS`'teki `/process\s*\.\s*binding\s*\(/` deseni
(`network-capability-guard.test.ts:101`). Bu desenin eşleşebildiği **düz biçimi** ürün koduna
yazdım:

```
src/features/usage/server/usage-aggregator.ts(273,25):
  error TS2339: Property 'binding' does not exist on type 'Process'.
```

Yani **desenin yakalayabildiği tek biçim bu depoda derlenmiyor.** Yazılabilir olan her biçim
(`process as unknown as …`, `const p: Process & {…} = process`, ara değişken) desenden kaçıyor.
Kalıcı negatif kontrol `:413` (`N2 — process.binding('tcp_wrap') … yakalanır`) fixture'ı **tipsiz
düz metin** kullandığı için yeşil; ürün kodunda **asla oluşamayacak** bir şekli test ediyor. Bu,
kendi hafıza notumdaki desenin (metinsel katman sondalarını "TypeScript'te gerçekten yazılabilir
biçimde" dene) birebir tekrarı ve tur 4'te not ettiğim borcun artık **kanıtlanmış** hâli.

**Dürüst sınıflandırma:** bu vektör **kasıt sınıfıdır** (kimse `TCPConnectWrap`/`WriteWrap` ile elle
HTTP çerçevelemeyi kazara yazmaz) — X1/V5 gibi *kaza sınıfı* değil. Tek başına olsaydı ÖNEMLİ derdim.
Bloklayıcı yapan iki şey: (a) brief'in GEÇTİ şartı bunu açıkça dışlıyor, (b) düzeltmesi **tek satır**
ve yeni mekanizmanın kendi felsefesiyle birebir uyumlu.

**Kapatmak için gereken minimum (1 satır):** sentinel'e ekle —
`patch(process as unknown as Record<string, unknown>, 'binding', 'process.binding')`.
Davranış tabanlı, sözdiziminden bağımsız, S2'yi **derhal** KIRMIZI yapar ve
`network-capability-guard.test.ts:101`'deki yakalanamayan regex'e olan bağımlılığı bitirir.
(Aynı yerde `process.dlopen` de kuşatılabilir — native addon yükleme, aynı ailenin diğer üyesi.)
